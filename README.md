# Orvibe

A live radio player built with Flutter (Android, iOS and web).

Web: https://sreedwish.github.io/radioProject/orvibeFM/

## Run

```
flutter pub get
flutter run -d chrome
```

## Deploy

Pushing to `main` builds the web app and publishes it to GitHub Pages through
`.github/workflows/deploy.yml`. In the repo settings, Pages → Source must be
**GitHub Actions**.
